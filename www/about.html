About This Project

Main Topic: VPN (Virtual Private Network)
Current Phase: Basic HTTP Web Server & Client in C

Objective

Develop a simple HTTP Server and Client that supports GET requests and serves static web pages from the www folder. This forms the foundation for understanding web communication before implementing VPN tunneling.

Project Goals

  • Implement socket programming and TCP connection handling
  • Parse HTTP/1.1 GET requests and generate proper responses
  • Serve HTML, CSS, images and other files with correct MIME types
  • Build groundwork for future VPN tunneling project
